# Game vision

Blackroot is a long-form pixel-art village-building survival RPG. Gruk is an ordinary Orc rebuilding a destroyed settlement, not a chosen hero. Active gathering, survival, exploration, skill mastery, crafting, social discovery and eventual economic independence should reinforce one another. Target ambition: 300–500 hours to kingdom-scale progression and 500–1000+ hours for mastery; not measured playtime. Slow meaningful upgrades, rare discoveries, humor and collections matter more than rapid completion.

Core loop: gather → survive → store resources → build → recruit workers → improve tools → explore → discover → trade → expand. Passive production supplements active play rather than replacing it. Early scarcity gives way to a functioning village. Avoid mandatory extreme RNG, especially mythic NPCs/fish. Keep optional collections permanent even when items are consumed or sold.

Riverhaven is a second settlement offering alternatives to chopping trees: trade, fishing, conversations, contracts and eventually diplomacy. It must look like the same world, not a placeholder map. Buildings should have meaningful interactions, and villagers should feel like people rather than UI markers. Keep humor grounded in fantasy occupations and personalities.

Platform: browser first, mobile-first usability with desktop preserved, eventual Capacitor/iOS considered (not committed implementation). Solo developer using VS Code, Codex, GitHub, Vercel. Design discussion in ChatGPT; implementation and verification locally.
